Standard BAU tasks, recurring procedures and runbooks for a Technical Support Engineer. This is
the IT/workplace-support sibling of the App Support BAU, and is listed here because Ron's team
sits alongside it and the ticket filters are shared.

## Access management tasks

- **Wifi Access**: network access configuration and troubleshooting.
- **HID Portal and Skytunnel** (door access). Docs at TO page 1968406831. Vendor contact:
  Nathan Gill, Automated Innovation. If slots run out, contact them to add more.
- **User Account Provisioning**: new user access setup across systems.
- **Permission Auditing**: regular review of user access rights.
- **Horizon Access**: add or update user permission/account.
- **Geolocation**: add a user to the group exempted from location checks.

## Network and infrastructure tasks

- Internet provider and connectivity troubleshooting.
- Unifi and Sophos network equipment and security appliances.
- VPN configuration: OpenVPN and Azure Client VPN.
- Network performance monitoring.
- Firewall rule management.

## Device management tasks

- Setup new laptop onboarding.
- Offboarding: secure device and account deactivation.
- Reset Windows, reset Mac.
- Asset tracking.

## Practices recorded on the page

Always document every solution, process and lesson learned. Communicate proactively. Ask
questions rather than assume. Focus on prevention and pattern spotting. Avoid: promising what
you cannot deliver, escalating too late or too early, skipping documentation, working in
isolation.
